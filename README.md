# SmartLearn Agent

An AI-powered learning assistant that helps students understand PDF documents through grounded questions, answers, summaries, and source references.

## Features (Planned)

- Upload PDF documents for analysis
- Ask questions about document content
- Generate grounded answers with page citations
- Generate summaries and study guides
- Support retrieval-augmented generation for long documents

## Tech Stack

- **Backend:** Python + FastAPI
- **Frontend:** React + Vite
- **AI:** OpenRouter-compatible LLM API
- **Retrieval:** Embeddings + FAISS
